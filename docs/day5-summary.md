# Day 5 总结：检索改进的评测、口径与决定

## 1. 评测对象
- 题目：20 道库内题（Q01-Q20），题单见 docs/eval-questions.md
- A（改进前）：中文原问题 → bge-m3 向量检索，取前 5
- B（改进后）：大模型把问题改写成 3 个英文问法；每个问法做向量检索和 BM25 关键词检索；
  用 RRF 融合，取前 5
- 评审：DeepSeek-V3.2 逐条判断"相关 / 部分相关 / 无关"

## 2. 两轮评测的口径（数字不可直接比较）

| | v1 | v2 |
|---|---|---|
| "相关"的标准 | 段落能直接回答问题 | 入门 PM 读完至少能拿到一条可直接用的具体方法或明确结论 |
| Hit@5：A → B | 60% → 60% | 60% → 50% |
| 严格 P@5：A → B | 22% → 21% | 20% → 20% |
| MRR：A → B | 0.44 → 0.42 | 0.43 → 0.34 |
| 宽松 P@5：A → B | 79% → 85% | 90% → 96%（已作废） |
| 结果文件 | docs/day5-results-v1.md | docs/day5-results-v2.md |

另有一版更宽松的标准（"读到一条可用的判断依据即相关"）只讨论过，没有运行。

指标含义：
- Hit@5：前 5 条里至少有 1 条"相关"的题目占比
- 严格 P@5：前 5 条里"相关"的比例
- MRR：第一条"相关"结果的排名倒数的平均值（排第 1 得 1，排第 2 得 0.5）

## 3. 已作废的指标
- 宽松 P@5：v2 把"部分相关"的定义放宽后，A 从 79% 升到 90%，几乎所有结果都能通过，没有区分度。
- 以后只看：Hit@5、严格 P@5、MRR。

## 9. 结论与决定
1. MVP 用中文原问题、单路向量检索；暂不使用提问改写和混合检索。
   - 原因：B 同时改了三件事（改写、BM25、融合），无法归因。
   - 改写在 Q19 上变差，在 Q02 上持平，样本仅 2 题，不足以断言"改写无效"。
   - 若以后恢复，一次只加一个变量。
2. 验收口径从块级改为回答级（见 PRD 修订记录）。
3. 拒答第一道只用向量最近距离，重排序分数不参与拒答。
4. 下一步：离线计算好内容的"进池率"，再接入重排序。

## 10. 局限
- 评审员与改写器是同一个模型。
- 评测只看前 5 条，没有计算召回率。
- 好内容清单有选择偏差。
- v2 标准未经人工抽检。
- 改写步骤不可复现：同一道题在两轮中得到不同的改写（如 Q01），
  而 A 两轮的最近距离差异不超过 0.001。因此 B 的两轮差异混合了评审标准变化和改写随机性，
  不能归因于任何单一原因。
- 样本仅 20 题。
